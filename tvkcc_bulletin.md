# Antigravity Weekly Bulletin Workflow

**Description:** This file contains the instructions for the Antigravity Agent to manage the TVKCC Weekly Bulletin translation. It supports both a hybrid automated flow (which leverages headless draft generation via GitHub Actions / Mac Mini) and a fully manual fallback flow.

---

## 🚀 Workflow Triggers

### 1. Hybrid Workflow (Recommended)
**Trigger:** `@tvkcc_bulletin.md Finalize the weekly bulletin translation for [YYYY-MM-DD]`
*Use this workflow when the automated scraper has already generated a draft file `drafts/weekly_translation_draft_[YYYY-MM-DD].md` in the repository.*

### 2. Manual Fallback Workflow (From Scratch)
**Trigger:** `@tvkcc_bulletin.md Execute the weekly bulletin translation from scratch`
*Use this workflow if the automated scraper was not run, or you need to re-generate everything manually.*

---

## 🤖 1. Hybrid Workflow Instructions (Recommended)

When the user triggers the hybrid workflow for a specific date (e.g. `2026-06-28`), execute these steps in order:

### Step 1. Pull Latest Changes & Retrieve Draft
- Run `git pull` via terminal to fetch the latest changes (including any automated drafts generated by GitHub Actions/cron).
- Verify that the draft file `drafts/weekly_translation_draft_[YYYY-MM-DD].md` exists. If it does not exist, notify the user and offer to run the manual scraper.
- Read and load the draft content.

### Step 2. User Review & Interactive Edits
- Display the English translation draft to the user.
- Ask the user to review the translations, specifically pointing out any newly translated community announcements.
- Allow the user to make adjustments or requests (e.g., "Change the location of Ladies Night to Gym"). Apply these edits to the draft.

### Step 3. Generate HTML Bulletin Page
Using the approved translation draft, generate the styled HTML bulletin at `docs/bulletins/[YYYY-MM-DD].html`. Follow the **HTML Layout Rules** (Section 3 below) to copy the structure of `master_template.html` and replace placeholders.

### Step 4. Update Main Archive List
- Update `docs/index.html` by adding a new `<li>` entry at the top of the `<ul class="archive-list">` for the new weekly bulletin (newest first).

### Step 5. Run Quality Verification
- Run `python3 scripts/validate_bulletin.py` to ensure static block consistency and week-over-week announcement text matching.
- Fix any issues identified by the script before proceeding.

### Step 6. Publish and Verify
- Commit and push the generated HTML page, updated index, and final draft:
  ```bash
  git add docs/bulletins/[YYYY-MM-DD].html docs/index.html drafts/weekly_translation_draft_[YYYY-MM-DD].md
  git commit -m "Publish weekly bulletin for [YYYY-MM-DD]"
  git push
  ```
- Use Chrome to open the final files:
  `open -n -a "Google Chrome" --args --new-window [URL to Korean PDF] file:///Users/youngjoo/Vibe/TVKCC%20Jubo/drafts/weekly_translation_draft_[YYYY-MM-DD].md file:///Users/youngjoo/Vibe/TVKCC%20Jubo/docs/bulletins/[YYYY-MM-DD].html`
- Clean up any temporary files: `rm -rf temp_extraction/`
- Provide the user with the public sharing URL: `https://youngkjoo.github.io/tvkcc-bulletin-automation/bulletins/[YYYY-MM-DD].html`

### Step 7. Sync Style Guides & Catalog
- If the user requested manual translation or formatting changes, update `bulletin_style_guide.md` and `bulletin_announcement_catalog.md` accordingly. Push these updates to GitHub.

## 🤖 2. Manual Fallback Workflow (From Scratch)

When the user triggers the manual fallback workflow, execute the following steps in order:

### Step 1. Retrieve the Latest Bulletin
- Use `read_url_content` on `https://www.tvkcc.org/weeklybulletins/` to read the webpage.
- Parse the output to find the link to the most recent weekly bulletin post.
- Use `read_url_content` on that post to extract the `.pdf` link.
- Use `curl` via `run_command` to download the PDF locally.

### Step 2. Retrieve Sunday Liturgy Title & Pope Intention
- Determine the upcoming Sunday date (or override date if specified).
- Scrape USCCB `https://bible.usccb.org/` to find the liturgy title for that Sunday.
- Search for the Pope's prayer intention for the current month.

### Step 3. Extract & Translate
- Extract PDF text using `pdfplumber` (saving intermediate files in `temp_extraction/`).
- Translate text using rules in `bulletin_style_guide.md` and templates in `bulletin_announcement_catalog.md`.
- Save the markdown draft to `drafts/weekly_translation_draft_[YYYY-MM-DD].md`.

### Step 4. Proceed with Generation, Verification & Publishing
- Continue from **Step 3 of the Hybrid Workflow** (HTML generation, index update, validation, push to git, browser verify, and style guide sync).

## 📐 3. HTML Layout Rules (Strict)

When generating the HTML bulletin page (`docs/bulletins/[YYYY-MM-DD].html`), copy the exact structure of `master_template.html` and replace the placeholders:

1. **Banner & Header** — Replace `{{ LITURGY_TITLE }}`, `{{ DATE_LONG }}`, and `{{ ISSUE_NUMBER }}`. Map the liturgical color of the week (Red, Green, Purple, White/Gold, or Rose) to the title bar CSS class (`liturgical-red`, `liturgical-green`, `liturgical-purple`, `liturgical-white`, or `liturgical-rose`). Append a cache-buster query parameter to the stylesheet link in `<head>` (e.g. `href="../style.css?v=[YYYYMMDD]"`).
2. **Mass Schedule Table** — Keep static elements. Update priest/Mass schedules if any changes are noted.
3. **Liturgy & Key Dates** — Replace with this week's `<ul class="liturgy-list">` items. Include sub-notes using `<span class="sub-note">`.
4. **Community Events Table** — Replace table rows with meetings details.
5. **Announcements Grid** — Replace with announcements in a two-column `<div class="announcements-grid">`. Keep the columns balanced.
6. **Offertory Table** — Replace the `{{ OFFERTORY_* }}` and `{{ DONOR_LIST_ITEMS }}` placeholders.
7. **Pope's Prayer Intention** — Replace the `{{ POPE_* }}` placeholders.
8. **Optional Blocks** — If optional blocks (such as Sunday School schedule or Pray for Us names) are not present in the draft, delete the entire optional HTML block.
9. **Navigation links** — Update `{{ PREV_BULLETIN_* }}` and `{{ NEXT_BULLETIN_* }}` links.
10. **Korean Bulletin Link** — Replace `{{ PDF_LINK }}` with the link to the original Korean PDF in the `<div class="korean-link-bar">` section.
